Island Adventure Game 🏝️

A simple Python text-based adventure game where the player makes choices to explore an island and find the winning path.

✨ Features

* Choose between different doors.
* Explore different rooms.
* Choose between different boxes.
* Receive different outcomes based on your choices.
* Win or lose depending on the path you choose.

🛠️ Technologies

* Python
* Conditional statements
* User input
* if, elif, and else

🚀 How to Use

1. Run the Python program.
2. Choose a door: red or blue.
3. If you choose red, select a box.
4. Follow the outcome of your choices.
5. Try to find the winning path.
